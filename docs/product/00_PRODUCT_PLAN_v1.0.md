# Programming Trainer 製品企画書 v1.0

## 1. 製品名
Programming Trainer

## 2. 製品コンセプト
PC Webブラウザ上で、講義を読むだけではなく実際にコードを書き、実行し、自動採点を受けながら段階的に学習するハンズオン型プログラミング学習アプリ。

## 3. 主対象
- プログラミング初学者
- 資格学習と実務練習をつなげたい学習者
- コードを「読む」だけでなく「書いて覚えたい」利用者
- Windows PC / Chrome / Edge を利用するユーザー

## 4. 対象言語
初期計画:
- Python
- Java
- C++
- Ruby
- JavaScript
- HTML
- CSS
- Windows Command
- PowerShell

将来候補:
- SQL
- Git
- Linux / Bash

## 5. レベル体系
### 3級
基礎を一人で書ける。
- 出力・入力
- 変数
- 型
- 演算子
- 条件分岐
- 繰り返し
- 配列/コレクション
- 文字列
- 基本関数

### 2級
小規模プログラムを組める。
- 関数・クラス
- 例外処理
- ファイル操作
- データ構造
- アルゴリズム
- モジュール分割
- デバッグ
- 小規模課題

### 1級
既存コードを理解し実務的に改修できる。
- 仕様変更
- バグ修正
- 複数ファイル
- テスト
- リファクタリング
- 既存システム改修

## 6. 学習体験
1. 言語を選択
2. レベルを選択
3. Lessonを開始
4. 解説・例を見る
5. コードを書く
6. 実行する
7. 自動テストで採点
8. ヒントを見る
9. 修正して再挑戦
10. 合格後に解説を確認
11. 進捗を保存
12. 章末課題・模擬試験へ進む

## 7. 差別化
- 問題集ではなくブラウザ内IDE中心
- 1問ごとの自動テスト
- 失敗テストの原因を確認可能
- 実行結果と採点結果を分離
- ヒントを段階表示
- 苦手Lessonを再提示
- 学習履歴・正答率・試行回数を保存
- 将来はHTML/CSSリアルタイムプレビュー
- 将来はCommand/PowerShell仮想ターミナル
- 同一UI思想で複数言語へ展開

## 10. 非機能方針
- PC Webを正式環境とする
- Chrome / Edgeの最新安定版
- 1280×720以上を最低基準
- 1920×1080を推奨
- キーボード操作を重視
- 学習データは初期はローカル保存
- 将来クラウド同期可能なID設計
- 実行コードがUIをフリーズさせない
- 任意コード実行はブラウザサンドボックス側に閉じる
- 外部ネットワークアクセスを教材の前提にしない

## 11. 成功条件
MVP時点:
- 初学者がブラウザだけでPython 3級基礎を一通り学べる
- 各Lessonでコードを実際に実行できる
- 自動採点により合否が明確
- 途中終了しても進捗が保持される
- 既存設計を壊さず他言語を追加できる
